بسته PWA داشبورد مدیریتی هنرستان پیشرو
======================================

محتویات:
- index.html              پوسته نصب‌پذیر برنامه
- config.js               محل وارد کردن نشانی وب‌اپ Google Apps Script
- manifest.webmanifest    مشخصات PWA
- sw.js                   سرویس‌ورکر و کش فایل‌های پوسته
- icons/                  آیکن‌های 192 و 512 و maskable

نکته مهم درباره معماری برنامه:
داشبورد ارسالی شما از google.script.run استفاده می‌کند. این قابلیت فقط وقتی صفحه
داخل محیط HtmlService گوگل اجرا شود کار می‌کند. بنابراین فایل HTML داشبورد و
کد GS را نمی‌توان بدون بازنویسی ارتباطات، مستقیماً روی GitHub Pages اجرا کرد.
این بسته، یک پوسته PWA روی GitHub Pages می‌سازد و داشبورد اصلی را از Web App
گوگل درون iframe نمایش می‌دهد.

مراحل آماده‌سازی:
1) در Google Apps Script، فایل HTML داشبورد را با نام Dashboard نگه دارید.
   کد gs ارسالی نیز باید در همان پروژه Apps Script باشد.
2) از Apps Script گزینه Deploy > New deployment > Web app را بزنید.
3) Execute as را متناسب با شیوه دسترسی مدرسه تنظیم کنید و دسترسی کاربران مجاز
   را تعیین کنید. سپس Deploy و نشانی Web app که به /exec ختم می‌شود را کپی کنید.
4) فایل config.js را باز کنید و مقدار GAS_URL را با نشانی واقعی جایگزین کنید.
   نمونه قالب نشانی:
   https://script.google.com/macros/s/شناسه-انتشار/exec
   فقط نمونه قالب است؛ شناسه واقعی را از حساب خودتان بردارید.
5) همه محتویات این پوشه را در ریشه یک مخزن GitHub بارگذاری کنید.
6) در مخزن GitHub از Settings > Pages، شاخه main و پوشه /(root) را انتخاب کنید.
7) پس از فعال شدن GitHub Pages، نشانی HTTPS سایت را باز کنید و مطمئن شوید
   داشبورد درون صفحه نمایش داده می‌شود.
8) همان نشانی GitHub Pages را در PWABuilder وارد و بسته Android را بسازید.

نکات امنیتی بسیار مهم:
- فایل gs(2).txt را در مخزن عمومی GitHub قرار ندهید.
- کد GS ارسالی شما شامل کد ثابت مدیر، رمز پیش‌فرض و شناسه Google Sheet است.
  مخزن عمومی می‌تواند این اطلاعات را در اختیار همه بگذارد.
- قبل از انتشار، کدهای ثابت ورود مدیر و رمز پیش‌فرض را در پروژه Apps Script
  تغییر دهید و برای حساب‌های پیش‌فرض رمز قوی تعیین کنید.
- فایل config.js فقط نشانی Web App را نگه می‌دارد؛ رمز عبور کاربران را در آن
  ننویسید.
- پوسته PWA به اینترنت نیاز دارد؛ فقط فایل‌های پوسته کش می‌شوند. داده‌ها و
  عملکرد داشبورد همچنان از Google Apps Script و Google Sheets دریافت می‌شود.
- اگر صفحه در iframe باز نشد، تنظیم X-Frame-Options و دسترسی انتشار Web App
  را در Apps Script بررسی کنید. در کد فعلی doGet شما ALLOWALL تنظیم شده است.

این بسته، کد GS را به GitHub منتقل نمی‌کند و فقط رابط نصب‌پذیر را میزبانی می‌کند.
